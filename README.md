PROGRAM FEATURES: 
Splits display screen into 4 separate quadrants. Depending on where on x/y axes the mouse is clicked, program will print the x/y coordinates of the mouse click in a unique font.
The program uses 4 fonts, 4 font colors, and 4 background colors associated with where the mouse is clicked:
1. UPPER RIGHT: black screen, white font
2. UPPER LEFT: white screen, black font
3. LOWER RIGHT: yellow screen, blue font
4. LOWER LEFT: blue screen, yellow font
A circle object will also appear where the mouse is clicked on screen. The color is purple so it shows up in all quadrant colors.
Program utilizes Allegro 5 and uses the Truetype Font, Primitives, Dialog, and Font add-ons. All of the ttf files used are included on this Github, so download as Zip and extract for proper installation.
